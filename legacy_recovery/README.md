# Historical recovery workflow

This folder preserves the original Desktop repository's Python source and
small experiment records. PROJECT_CONTEXT.md, CODEX_REPORT.md and AI_USAGE_LOG.md
are dated historical notes, not the current status of both article experiments.

The original Stage 4 and Stage 5 learning-rate screens differ from the article
recovery archive under ../recovery/. Keep those procedures and findings separate.
Stage 6 is a five-fold **recovery** comparison; the saved experiment_summary.json
reports four completed and 56 pending runs. It is not a finished segmentation
experiment or completed 60-run result.

Model weights and raw-best .npz checkpoints are omitted from this Git tree.
Historical Stage 5/6 resume and preflight audits require those omitted artifacts
from the original repository. No historic scripts or results were rerun here.
Preserved Stage 3 figures belong to the pilot, which used plain SGD and MSE.
